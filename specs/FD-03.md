# FD-03: CI is red, laptops are green

**Size:** S

## Background

Every pull request's CI run has been failing, but nobody can reproduce it: `npm test` passes on every laptop. CI runs `npm run check` with the test order shuffled and prints the seed at the top of the test step. `KNOWN_FAILURES.md` lists one test as a known failure.

## Acceptance criteria

1. The unit suite passes in the default order and in every shuffled order, run the way CI runs it (`TZ=UTC`, `--sequence.shuffle --sequence.seed=<n>`).
2. A fresh CI run on `main` is green.
3. No test is deleted, skipped or loosened to get there. The suite has at least as many passing tests as before.
4. The automation rules behave exactly as before: `npm run rules:parity` passes.
5. `KNOWN_FAILURES.md` lists only failures that still happen.
