# FD-01: Tag counts in the sidebar

**Size:** S

## Background

Teammates triage from the Tags list in the inbox sidebar. They want to see how many tickets carry each tag without clicking through every tag.

## Acceptance criteria

1. Each tag in the inbox sidebar shows the number of tickets that carry it, after the tag's name (for example, "billing 4").
2. The count follows the status the inbox is showing. On Open it counts open tickets, on Pending pending tickets, on Closed closed tickets, and on All every ticket.
3. A tag with no tickets in the current view shows 0 and stays in the list.
4. Every tag returned by `GET /api/tags` includes a `ticketCount`. The endpoint accepts an optional `status` query parameter (`open`, `pending` or `closed`). With it, `ticketCount` counts tickets in that status; without it, every ticket. Counts reflect tag changes immediately.
5. An unknown `status` value is rejected with `400`.
6. The OpenAPI contract describes the new field and parameter, and the generated types match it.
7. Filtering the inbox by clicking a tag works as it does today.
