# FD-02: Latin-1 subjects are garbled

**Size:** S

## Background

Some customers' mail programs send headers in ISO-8859-1 (Latin-1) instead of UTF-8. Those tickets show up in the inbox with replacement characters where the accented letters should be. Ticket #36 in the seeded inbox, from Cabinet Gagnon, is one: its subject should read "Épreuves des cartes de visite : délai de livraison?".

To reproduce with a fresh message, run `npm run mail:drop -- poster-reprint-quote` while `npm run dev` is running.

## Acceptance criteria

1. A subject made of ISO-8859-1 encoded words, in either the `Q` or the `B` encoding, is stored and shown with the right characters. The charset label is matched without regard to case. Encoded words can be mixed with plain text and can be folded across header lines.
2. The sender's display name is decoded the same way, so the customer's name is right too.
3. Subjects and names that are UTF-8 or plain ASCII come out exactly as they do today.
4. After `npm run reset`, ticket #36 shows "Épreuves des cartes de visite : délai de livraison?", and dropping `poster-reprint-quote` creates a ticket titled "Devis pour une réimpression d'affiches" from "Renée Dubé".
5. `npm run check` stays green.

## Out of scope

- Message bodies in other character sets.
- Character sets other than ISO-8859-1 and UTF-8.
